## Tools
- **Playwright** v1.63.0 installed globally (`npx playwright`)
- **ui-ux-pro-max-cli** available via `npx ui-ux-pro-max` or `npm install -g ui-ux-pro-max-cli`

## Usage
```bash
# Use skills via npx
npx skills add <repo>

# Design system generation
python3 .claude/skills/ui-ux-pro-max/scripts/search.py "SaaS dashboard" --design-system --persist -p "POS-CAFE"

# Playwright CLI
npx playwright --help
```
